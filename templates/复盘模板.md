### 2. 中段行不行 —— 看衰减比

```
衰减比 = 完播率 / 3 秒完播率
```

| 衰减比 | 含义 |
|---|---|
| ≥ 0.55 | 中段很稳，观众看完了 |
| 0.40-0.55 | 正常 |
| 0.25-0.40 | 中段拖，有明显掉量点 |
| < 0.25 | 观众在某个位置集体划走，必须找出来 |

**如果衰减比 < 0.4**：回看后台的留存曲线，找出掉量的具体秒数，那里一定有一句废话。

### 3. 值不值得复制 —— 看涨粉效率

```
涨粉率 = 涨粉 / 播放 × 1000   （每千播放带来几个粉）
```

| 涨粉率 | 判断 |
|---|---|
| ≥ 8 | 内容有强系列感，可做成固定栏目 |
| 3-8 | 正常 |
