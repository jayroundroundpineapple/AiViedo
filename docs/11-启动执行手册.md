> 前面 10 份文档解决「为什么这样做」，这份只解决「明天打开电脑第一件事做什么」。
> 记录时间 2026-11。涉及平台规则与价格的，以 App 后台实际显示为准。

## 一、方向：三选一，今天定，30 天不改

不要"再看看"。三个方向的分水岭是**商单品类宽度**和**一致性难度**，不是"哪个好看"。

| | A 拟人小动物 | B 中式小神仙 / 妖怪 | C 抽象潮玩小怪物 |
|---|---|---|---|
| 举例 | 圆脸橘猫「年糕」，短腿、黄雨衣、黄铜铃铛 | 掌管下雨的小龙女、爱睡觉的山神 | 一团会发光的果冻状生物 |
| 一致性难度 | **低**（AI 对动物形象最稳） | 中（服饰纹样容易漂） | **高**（抽象形态容错大但记不住） |
| 能接的商单 | 宠物食品、猫砂、零食、文具、盲盒、童装、家居、APP | 国风服饰、茶饮、文旅、游戏、文创 | 盲盒、潮玩、APP、数码、饮料 |
| 情感连接 | 强（能讲故事） | 中（偏视觉） | 弱（不好做剧情） |
| IP 授权潜力 | 中 | 中高 | **最高** |
| 上手速度 | **最快** | 慢 | 最慢 |

**推荐 A。** 三个理由：
1. **商单品类最宽**——宠物、食品、文具、家居都能投，不会因为"画像对不上"被压价（见 `docs/10` 第三节）
2. **一致性最容易**——你的最大技术风险是"第 5 条视频里主角长得不像第 1 条"，动物形态对 AI 的容错远高于人物和服饰
3. **一次素材三个出口**——壁纸、头像、宠物肖像定制，同一批图

**B 的问题**是好看但商单窄（国风品牌预算集中且要求高）。**C 的问题**是前期做不出内容，你会在第 3 周就没东西可发。

如果选 B 或 C，只有一个理由成立：你本人长期喜欢那个审美。**喜欢才能做满 12 个月，这比商单宽度重要。**

## 二、角色卡：一张纸定死，之后所有生成都用它

这是整个项目最重要的一份文件。定完存成 `01_原创角色/角色卡.txt`，每次生成原样复制，**一个词都不改**。

### 模板

```
【固定描述串】
年糕，一只圆脸的橘白小猫，短腿，圆眼睛，脖子上挂一枚小小的黄铜铃铛，
穿明黄色雨衣，腮红明显，3D 渲染质感，柔和顶光，浅灰纯色背景

【固定风格】
3D 皮克斯质感（三选一：3D 皮克斯 / 扁平插画 / 水彩，定了不改）

【固定比例】
3:4 → 小红书笔记
9:16 → 手机壁纸
1:1 → 头像
```

### 角色卡必须包含的四样

1. **三视图**：正面、侧面、背面（这三张以后所有生成的参考基准）
2. **5 种表情**：笑、惊讶、难过、生气、困
3. **3 个常用动作**：坐着、走路、伸手
4. **2 个固定场景**：家里（暖色）、外面（雨天 / 夜晚）

存两套分辨率：`9:16` 和 `3:4`。**这一张卡是你后面所有内容的资产**，比任何一条视频都值钱。

### 一致性三条铁律

- 描述串**一字不改**，要改风格就重做角色卡，不要中途微调
- 用"参考图"功能（即梦的参考图、Midjourney 的 `--cref`）挂三视图，不要只靠文字
- 每月只在月底评估一次要不要升级角色，中途不换

## 三、选品：四层货架，先上三个

### 产品阶梯

| 层 | 产品 | 定价 | 作用 | 什么时候上 |
|---|---|---|---|---|
| **引流** | 3–9 张壁纸试用装 | 免费 | 换关注、换评论、换收藏 | 第 1 周 |
| **入门** | 壁纸包 30 张（4 个尺寸） | **¥9.9** | 跑通"有人愿意付钱" | 第 1 周 |
| **现金** | 头像定制（1 张 + 改 1 次） | **¥29** | 现金流，成交路径最短 | 第 1 周 |
| **高客单** | 宠物拟人肖像（把你的猫变成这个画风） | **¥199** | 提客单价，情绪价值溢价 | 第 1 周 |
| **复利** | 素材包（三视图 + 表情 + 场景 + 提示词） | ¥29 | 卖给同行 / B 端，零边际成本 | 第 3–4 周（攒够 50 个素材） |
| **海外** | Fiverr 定制 Gig | **$35 起** | 同一张图，价高 5–10 倍 | 第 2 周 |

### 三个判断

1. **表情包不要当 SKU 卖。** 小红书没人花 ¥9.9 买表情包，但**免费发出去能换大量收藏和关注**。它的定位是传播工具，不是收入。
2. **¥9.9 的作用不是赚钱，是筛人。** 愿意付 ¥9.9 的人里，会有 10%–20% 后来买 ¥199 的定制。所以别嫌便宜。
3. **¥199 宠物肖像才是真正的现金牛。** 用户为自己的宠物付费的意愿，远高于为自己买壁纸。而且改稿边界清楚（"固定 3 版供选，改稿 2 轮内"）。

### 上架三个技术坑（都踩过）

- **虚拟商品必须建「0 元包邮」运费模板**，否则无法过审
- 类目选「虚拟商品 / 电子资料」，不要选实物类目
- 详情页**写清交付方式**（网盘链接 / 自动发货）和「虚拟商品不支持退款」

**保证金**：小红书个人店部分类目需缴 1000 元（可后缴，以后台提示为准）。**别在没跑通前就缴。**

## 四、30 天排期（每天 1 小时，每周 7 小时）

### 第 1 周：搭地基（不做视频）

| 天 | 动作 | 时间 | 验收 |
|---|---|---|---|
| **D1** | 选方向（A/B/C）→ 定角色名 + 3 个风格关键词；小红书升级个人专业号 + 实名；开个人店 | 60 分 | 店铺能进后台 |
| **D2** | 出角色卡：三视图 + 5 表情 + 3 动作 + 2 场景 | 90 分 | `角色卡.txt` 存好 |
| **D3** | 批量出图 60 张，留 30 张能看的，分 3 个系列 | 60 分 | 30 张入 `03_AI图片素材/` |
| **D4** | 上架 3 个 SKU（¥9.9 / ¥29 / ¥199）+ 建 0 元包邮模板 | 60 分 | 店铺有 3 个商品 |
| **D5** | 发第 1 篇笔记（成品效果图 + 标题带搜索词） | 40 分 | 笔记通过审核 |
| **D6** | 发第 2 篇（另一系列） + 回复所有评论 | 40 分 | — |
| **D7** | 发第 3 篇 + 登记台账 + 看 3 篇的曝光/阅读/收藏 | 40 分 | 台账 3 行 |

**D7 验收：店铺 3 个商品、主页 3 篇笔记。不看粉丝。**

### 第 2 周：开双线

| 天 | 动作 |
|---|---|
| D8 | 抖音图文 1 篇（小红书内容改标题复用） |
| D9 | 剪第 1 条视频（角色小剧情，30–45 秒） |
| D10 | 抖音图文第 2 篇 + 视频发布（小红书 + 抖音） |
| D11 | 注册 Fiverr，写 1 个 Gig（$35 宠物肖像定制） |
| D12 | 抖音图文第 3 篇 |
| D13 | 剪第 2 条视频（成品卡点，8–15 秒） |
| D14 | 复盘：3 篇笔记的收藏率，哪篇最高？为什么？ |

**D14 验收：抖音 3 篇图文 + 视频 1 条 + Fiverr 1 个 Gig 上线。**

### 第 3 周：加厚度

- 第二批 30 张图（延伸系列，不换角色）
- 上架素材包 ¥29
- 视频第 3、4 条（其中 1 条拍"制作过程"，是信任工具）
- 抖音发到 1000 粉的一半就够，别急着冲

### 第 4 周：复盘与决策

- 补齐第 5、6 条视频
- 台账汇总：**总曝光 / 总阅读 / 收藏率中位数 / 店铺访问 / 成交单数**
- 按 `docs/10` 第七节的信号表决定：加量、改形态、还是继续

**D30 唯一硬指标：有没有 ≥1 单成交（哪怕 ¥9.9）。** 没有成交就看收藏率中位数：
- ≥5% → 内容有价值，继续，改封面和标题
- 2%–5% → 换选题角度
- <2% → 换内容形态（不是换平台）

### 配图顺序（决定点击率）

| 位置 | 放什么 |
|---|---|
| 第 1 张 | **成品效果**（最好看的一张，直接当封面） |
| 第 2–3 张 | 更多成品，展示"一组有 9 张" |
| 第 4 张 | 用在手机上的实拍/合成效果（有场景感） |
| 第 5 张 | 引导："主页有完整包" |

**第 1 张不是过程图、不是文字图、不是拼图。** 用户刷到时 0.3 秒决定点不点。

## 六、台账：只记 5 个数

用 `data/notes.csv`，每篇笔记一行：

| 字段 | 说明 | 用途 |
|---|---|---|
| 曝光 | 后台"曝光量" | 分母 |
| 阅读 | 后台"阅读/观看" | 算点击率 |
| 收藏 | — | 算收藏率，判断内容值不值钱 |
| 店铺访问 | 后台"店铺访问" | 判断导流有没有通 |
| 成交 | 单数 | 唯一硬指标 |

三个派生指标：

- **封面点击率** = 阅读 ÷ 曝光。< 8% → **换封面，不是换内容**
- **收藏率** = 收藏 ÷ 阅读。≥5% 能卖；<2% 连发 7 篇就换方向
- **搜索进入占比** = 搜索流量 ÷ 总阅读。**这是被动收入的命门，越高越值钱**

## 八、五件不做的事（省下的时间比做的更值钱）

1. **不做日更。** 每周 3 篇图文 + 2 条视频是上限，超了必崩
2. **不做纯视觉奇观。** 打分 4.50，已放弃（见 `docs/10`）
3. **不做 AI 工具教学号。** 打分 4.90，粉丝画像卖不出去
4. **不买粉、不买赞。** 星图要"有效粉"（滚动 30 天），刷的不算，还限流
5. **不接纯置换。** 占一周产能，换不来现金，也换不来可复用的商单案例
