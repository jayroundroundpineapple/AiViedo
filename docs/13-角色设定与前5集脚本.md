## 一、为什么是这两个角色

四条设计约束，全部来自 `docs/12` 里四个爆款账号的共性：

| 约束 | 依据 | 本案怎么满足 |
|---|---|---|
| 必须两个角色且有稳定关系 | 猫子柒加第二只猫才好看、阿黄加小女孩才有情感 | 合租室友，一个拼命一个躺平 |
| 视觉必须强对比 | 呱呱历险记一红一绿才有辨识度 | 矮胖灰 vs 高瘦橘 |
| 必须能无限产出剧情 | 连续剧最怕没题材 | "打工人日常"天然有 50+ 个选题 |
| 必须能接商单 | 商单要靠粉丝画像 | 宠物用品、零食、外卖、小家电、租房、文具全部能投 |

**核心冲突一句话：麻薯越努力越倒霉，大吉越躺平越走运。**

这一句就是整部剧的引擎。它是打工人最共情的痛点，也是喜剧最容易出效果的结构——不需要想新题材，只需要把"一件事"分别交给两个角色处理，冲突自动产生。

## 二、角色 A · 麻薯

| 项 | 设定 |
|---|---|
| 物种 | 仓鼠（矮、圆、短腿） |
| 视觉 | 奶黄色，肚子更浅，塌耳朵，圆框眼镜，永远穿一件起球的灰色针织背心 |
| 体型 | 站着只到大吉的胸口 |
| 性格 | 焦虑、要强、抠门、嘴硬心软 |
| 身份 | 公司小职员，加班最狠的那个人 |
| 口头禅 | **"这个月一定能存下钱。"**（每次都失败） |
| 标志动作 | 紧张时推眼镜；算账时掏出计算器；说大话时手在背后偷偷攥紧 |
| 音色 | 偏高、语速快、有点喘——"像总在赶时间的人" |

### 固定描述串（每次生成原样复制）

```
麻薯，一只矮胖圆润的奶黄色仓鼠，肚子浅色，塌耳朵，戴圆框眼镜，
穿一件起球的灰色针织背心，短腿，眼睛小而有神，表情总是紧张，
3D 皮克斯渲染质感，柔和顶光，浅灰纯色背景
```

## 三、角色 B · 大吉

| 项 | 设定 |
|---|---|
| 物种 | 橘猫（高、瘦、长腿） |
| 视觉 | 橘色虎斑，白色下巴和四只爪子，头顶一撮永远翘起来的毛，穿人字拖 |
| 体型 | 高，站着比麻薯高一个头 |
| 性格 | 懒、松弛、运气好到离谱、话少但句句致命 |
| 身份 | 不上班。靠遛狗、帮邻居搬东西、捡别人不要的东西过活 |
| 口头禅 | **"急什么呢。"** |
| 标志动作 | 说这句话时慢慢眨眼；躺着用尾巴勾东西；永远在吃或准备吃 |
| 音色 | 偏低、语速慢、尾音拖长——"像刚睡醒的人" |

### 固定描述串（每次生成原样复制）

```
大吉，一只高瘦的橘色虎斑猫，白色下巴和四只爪子，头顶一撮翘起的毛，
穿人字拖，眼神慵懒半睁，身体修长，姿态总是躺着或靠着，
3D 皮克斯渲染质感，柔和顶光，浅灰纯色背景
```

**两人音色必须反差极大，观众闭眼能分辨。定了就永不更换。**

## 四、关系：一句话说清

**合租室友。麻薯以为自己在养这个家，其实一直在被大吉养。**

- 麻薯每天加班，觉得大吉是废物
- 大吉每天躺着，从不解释，默默兜底
- 每集的结构都是：**麻薯努力 → 失败 → 发现大吉早就在托底 → 嘴硬不承认**

这个结构能重复用几十次不腻，因为观众每次都在等那个"发现"的瞬间。这也是涨粉的核心——**观众关注的是"下一次它又会怎么默默帮他"**，不是"这只猫好可爱"。

### 六条可复用剧情公式（每集套一个）

1. **努力翻车**：麻薯拼命做一件事，结果一团糟，大吉随手搞定
2. **嘴硬打脸**：麻薯立 flag → 立刻破功 → 大吉假装没看见
3. **争抢推让**：两人抢一样东西 → 越推越假 → 最后东西没了
4. **隐瞒发现**：大吉偷偷做了什么 → 麻薯误会 → 结尾揭穿
5. **外部压力**：房租/老板/亲戚/体检 → 两人被迫合作
6. **生病示弱**：一方出状况，另一方露出真面目

## 五、世界观与固定场景

**设定：两个动物住在一间城市老破小里，周围全是人类，但没有一张人类正脸。**

这条设定同时解决三件事：避免肖像权、降低生成难度、强化"动物世界"的代入感。

| 场景 | 细节（生成时必须带上） | 用途 |
|---|---|---|
| **客厅** | 一张塌了一边的旧沙发、一台小风扇、冰箱门上贴满水电费单、地板是旧木地板 | 主场景，60% 的戏在这 |
| **便利店** | 深夜白光、货架、玻璃门反光 | 夜戏、买醉、加班回家 |
| **地铁** | 早高峰、扶手、人群的腿（只拍腿和包） | 通勤、挤、累 |
| **楼下小公园** | 一张长椅、一棵树、路灯 | 谈心、结尾留白 |

### 拍摄禁忌（三条，违反就废）

1. **不出现人类正脸**，只出现手、腿、背影
2. **机位永远压低**（动物视角，离地 20–30cm），这条决定"这是动物的世界"
3. **每集必须有一个固定场景**（客厅），让观众有归属感

## 六、前 5 集脚本

**通用参数**：竖屏 9:16 · 60–90 秒 · 8–10 个镜头 · 无人类正脸 · 全程字幕
**通用结构**：0–3s 钩子 → 3–15s 情境 → 15–60s 冲突升级 → 60–75s 反转 → 75–90s 追更钩子

---

### 第 1 集《数钱》· 悬念式 · 75 秒

**设计意图**：用"反常画面"当钩子，第一集必须让观众在 3 秒内产生"这是什么"的疑问。同时用一句话把两个角色的关系和经济落差交代完——后面所有剧情都建立在这个落差上。

| 镜 | 秒 | 画面 | 台词 / 字幕 |
|---|---|---|---|
| 1 | 0–3 | **特写**：一沓零钱在桌上被数，数钱的是橘色的猫爪 | （只有数钱声，无台词） |
| 2 | 3–8 | 全景：凌晨的出租屋，门开，麻薯进来，领带歪了，黑眼圈 | 无 |
| 3 | 8–15 | 麻薯看着桌上的钱，僵住 | 麻薯："你……哪来的钱？" |
| 4 | 15–25 | 大吉躺着数钱，头都不抬 | 大吉："遛狗。" |
| 5 | 25–40 | 麻薯掏出工资条，手抖 | 麻薯："遛狗？我加班到凌晨三点！" |
| 6 | 40–55 | 大吉终于抬头，慢慢眨眼 | 大吉："你算一下时薪。" |
| 7 | 55–65 | 麻薯掏计算器，越算脸越白，眼镜滑下来 | 字幕：**麻薯时薪 ¥4.2　大吉时薪 ¥38** |
| 8 | 65–72 | 麻薯解下领带，扔进垃圾桶 | 无 |
| 9 | 72–75 | 大吉抬头，尾巴一动 | 大吉："明天，跟我去遛狗？"<br>黑屏：**第 2 集 · 麻薯的第一天遛狗** |

**可植入商单**：无（前 3 集不接商单，先立角色）

---

### 第 2 集《戒炸鸡》· 反差式 · 70 秒

**设计意图**：反差式是传播最强的一种——先卖萌 3 秒，第 4 秒给冲突。这一集是第一次展示"大吉的默默托底"，把喜剧转温情，是涨粉的关键一集。

| 镜 | 秒 | 画面 | 台词 / 字幕 |
|---|---|---|---|
| 1 | 0–3 | 麻薯站在体重秤上，数字疯狂跳动最后显示 `ERROR` | 无 |
| 2 | 3–10 | 麻薯叉腰立 flag，背景大吉正在啃炸鸡 | 麻薯："从今天起，戒炸鸡。" |
| 3 | 10–20 | 大吉把炸鸡递过去，麻薯一巴掌推开 | 大吉："急什么呢。" |
| 4 | 20–35 | 深夜。麻薯在床上睁眼，肚子叫。摸黑走到冰箱 | 字幕：**凌晨 2:47** |
| 5 | 35–45 | 打开冰箱——一份炸鸡，贴着便签 | 便签特写：**"给你的。别装。"** |
| 6 | 45–55 | 麻薯愣住，回头。沙发上"睡着"的大吉，尾巴动了一下 | 无 |
| 7 | 55–65 | 麻薯坐下吃，吃得极快，一边吃一边掉眼泪（喜剧化的哭） | 无 |
| 8 | 65–70 | 字幕卡 | **第二天体重：+0.3kg**<br>大吉画外音："你看，我就说急什么呢。"<br>黑屏：**第 3 集 · 最后一个肉包** |

**可植入商单**：炸鸡 / 零食 / 外卖平台（第 5 镜冰箱里的包装是天然植入位）

---

### 第 3 集《最后一个肉包》· 日常式 · 65 秒

**设计意图**：日常式完播最稳，用来"稳住"观众。这一集测试的是"两人互相推让"的喜剧节奏——纯笑点，不带情绪，用来调节前两集的浓度。

| 镜 | 秒 | 画面 | 台词 / 字幕 |
|---|---|---|---|
| 1 | 0–3 | 桌上一个肉包，两只手同时伸过去，撞在一起 | 无 |
| 2 | 3–10 | 两人对视，谁也不松手，僵持 | 无 |
| 3 | 10–20 | 特写两只手在包子上较劲 | 麻薯："你昨天吃了。"<br>大吉："你前天吃了。" |
| 4 | 20–35 | 推让拉锯战，越推越客气，越客气越假 | 麻薯："你吃你吃。"<br>大吉："不不不，你吃。" |
| 5 | 35–42 | 麻薯想出办法 | 麻薯："要不……一人一半？" |
| 6 | 42–50 | 拿刀，切下去的瞬间，窗外一只流浪猫跳进来，叼走整个包子 | （一声猫叫 + 风声） |
| 7 | 50–60 | 两人追出门，镜头留在空桌上 | 字幕：**追了三条街** |
| 8 | 60–65 | 两人气喘吁吁回来，各拎一袋包子 | 大吉："你看，急什么呢。"<br>麻薯无语<br>黑屏：**第 4 集 · 大吉不动了** |

**可植入商单**：便利店 / 包子 / 速冻食品

---

### 第 4 集《大吉不动了》· 情绪式 · 85 秒

**设计意图**：**这集是整个系列最可能爆的一集。** 情绪式涨粉最稳，而"以为对方要死了，结果是心疼你加班"是极强的情绪反转。这一集之后，观众会开始真正喜欢这两个角色，不只是觉得好笑。

| 镜 | 秒 | 画面 | 台词 / 字幕 |
|---|---|---|---|
| 1 | 0–3 | 大吉躺在沙发上一动不动。麻薯叫它，没反应 | 麻薯："大吉？" |
| 2 | 3–12 | 麻薯摸它的头，手在抖。镜头怼近大吉闭着的眼 | 无 |
| 3 | 12–25 | 麻薯掏手机，给老板打字"今天请假"，删掉，又写，又删 | 字幕：**（打了 4 遍）** |
| 4 | 25–35 | 手指按下发送。屏幕"已发送" | 无 |
| 5 | 35–50 | 麻薯煮粥，完全不会，厨房一团糟（米撒了一地） | 无 |
| 6 | 50–62 | 回头看沙发——大吉睁着眼看它 | 大吉："你在干嘛？"<br>麻薯："你不是病了吗！" |
| 7 | 62–72 | 大吉慢慢坐起来 | 大吉："我没病。"<br>大吉："我就是想让你今天别去上班。" |
| 8 | 72–82 | 麻薯愣住，然后蹲下来，把脸埋进沙发。镜头不动 | 无（只有风扇声） |
| 9 | 82–85 | 大吉拍拍它的头 | 大吉："粥糊了。"<br>黑屏：**第 5 集 · 房租日** |

**可植入商单**：电饭煲 / 厨房小家电 / 米（第 5 镜厨房是天然场景）

### 第 5 集《房租日》· 悬念式 · 80 秒

**设计意图**：用一个外部压力把两人绑在一起，结尾给"铁罐"这个大钩子——**这是第一季的情绪最高点，也是让观众从"看"变成"追"的一集。**

| 镜 | 秒 | 画面 | 台词 / 字幕 |
|---|---|---|---|
| 1 | 0–3 | 门被敲响。三下，很重。两人同时抬头 | 字幕：**房租日** |
| 2 | 3–10 | 桌上摊着一堆零钱，两人数了一遍，不够 | 无 |
| 3 | 10–20 | 麻薯翻遍所有口袋，只掏出三个硬币 | 麻薯："这个月……" |
| 4 | 20–32 | 敲门声变急。麻薯开始发抖 | 无（敲门声加重） |
| 5 | 32–42 | 大吉慢慢站起来，走向角落的柜子 | 无 |
| 6 | 42–52 | 打开柜子，拿出一个旧铁罐（饼干罐），罐身有锈 | 无 |
| 7 | 52–65 | 倒出来——满满一罐硬币和零钱，铺满桌面，正好够 | 麻薯："你哪来的？"<br>大吉："遛狗的时候，别人不要的。" |
| 8 | 65–76 | 麻薯拿起空罐子，罐身贴着一张褪色的小纸条 | 纸条特写：**"给麻薯的"** |
| 9 | 76–80 | 麻薯抬头看大吉，大吉已经走去开门。门的影子投进来 | 黑屏：**第 6 集 · 待定** |

**可植入商单**：存钱罐 / 收纳 / 租房平台

## 七、一致性检查清单（每集发之前过一遍）

- [ ] 麻薯：眼镜、灰色起球背心、塌耳朵、矮胖——三样缺一不可
- [ ] 大吉：头顶翘毛、人字拖、白色下巴和四爪、高瘦——四样缺一不可
- [ ] 客厅：塌沙发、小风扇、贴满单子的冰箱——三样至少有一样入画
- [ ] 机位：全程低机位，没有一张人类正脸
- [ ] 声音：麻薯快而高、大吉慢而低，这集有没有混
- [ ] 结尾：有没有留追更钩子 + 下一集标题
- [ ] 标识：**发布时勾选 AI 生成标识**

**任何一项不过，重做。** 观众不会因为画质差取关，但会因为"第 5 集的主角不像第 1 集"取关。

## 八、生成工作流（一次 4 小时，出 3 集）

```
① 复制两个角色的固定描述串 → 出三视图（正/侧/背），存成参考图
② 用参考图 + 场景描述，批量出 40 个镜头（不是 40 张图，是 40 个"镜头构图"）
③ 图生视频：每个镜头抽 3–5 次，留下能用的
④ 配音：先录麻薯（快），再录大吉（慢），分开录，不要一次录完
⑤ 剪辑：字幕字号统一、片头固定 3 秒、片尾固定 2 秒
```

**单条成本上限 ¥30**，超了就减镜头数，不要加抽卡次数。
