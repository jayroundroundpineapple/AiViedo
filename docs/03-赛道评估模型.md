# 03 · 赛道评估模型

> 选赛道最大的问题是「凭感觉」。这份模型把它变成六个可打分的维度，**总分 ≥ 7 才允许立项**。

---

## 一、六个维度

每个维度 0-10 分，其中两个是**反向指标**（分越高越差），计算时会被反转。

| 维度 | 字段 | 方向 | 问自己的问题 |
|---|---|---|---|
| **需求热度** | `score_need` | 正 | 这个内容有人主动搜吗？搜索量/播放量在涨还是跌？ |
| **竞争强度** | `score_comp` | **反** | 头部是否已经固化？新人还有没有位置？ |
| **变现距离** | `score_money` | 正 | 从内容到收钱要几步？一步（带货）还是五步（先涨粉再想）？ |
| **可持续性** | `score_durable` | 正 | 这个题材我能做满 100 条不重复吗？ |
| **资源匹配** | `score_fit` | 正 | 我有没有别人没有的信息、渠道、技能、身份？ |
| **合规风险** | `score_risk` | **反** | 有没有肖像、医疗、金融、版权方面的硬伤？ |

---

## 二、打分锚点（避免全打 7 分）

打分最容易失效的地方是「都打 7 分」。请对着下面的锚点打。

### 需求热度 `score_need`

| 分 | 判断 |
|---|---|
| 9-10 | 平台有明确的话题标签且持续产出爆款，搜索指数上升 |
| 7-8 | 有稳定受众，但不算爆发期 |
| 4-6 | 只有零星爆款，看不出趋势 |
| 1-3 | 搜不到相关内容，或明显在衰退 |

### 竞争强度 `score_comp`（反向）

| 分 | 判断 |
|---|---|
| 9-10 | 头部账号垄断流量，新号 3 个月起不来 |
| 7-8 | 有成熟玩家，但仍有细分空位 |
| 4-6 | 竞争分散，没有绝对头部 |
| 1-3 | 几乎没人做（注意：也可能是没需求） |

### 变现距离 `score_money`

| 分 | 判断 |
|---|---|
| 9-10 | 视频里直接挂车/挂链接就能成交 |
| 7-8 | 有明确的服务可卖，评论区可私信转化 |
| 4-6 | 需要先建立信任，1-3 个月后变现 |
| 1-3 | 只能靠广告分成或卖号 |

### 可持续性 `score_durable`

| 分 | 判断 |
|---|---|
| 9-10 | 题材可无限延展（如「每天一个冷知识」） |
| 7-8 | 能撑 50 条以上 |
| 4-6 | 20 条后开始重复 |
| 1-3 | 一次性热点，做 3 条就没了 |

### 资源匹配 `score_fit`

| 分 | 判断 |
|---|---|
| 9-10 | 我有独家信息源/行业身份/现成客户 |
| 7-8 | 我比普通人多懂一点，且愿意持续投入 |
| 4-6 | 只能靠公开信息，没有差异化 |
| 1-3 | 完全外行，纯靠 AI 硬凑 |

### 合规风险 `score_risk`（反向）

| 分 | 判断 |
|---|---|
| 9-10 | 涉及医疗诊断、金融荐股、真人肖像、影视二创 |
| 7-8 | 涉及功效宣称、未成年人、敏感行业 |
| 4-6 | 需要标注广告，但无硬性资质 |
| 1-3 | 纯知识/娱乐，几乎无风险 |

## 三、加权与阈值

权重设计原则：**能不能活下去看变现，能不能持续看可持续性，别死在合规上。**

| 维度 | 权重 |
|---|---|
| 需求热度 | 0.20 |
| 竞争强度（反向） | 0.20 |
| 变现距离 | 0.25 |
| 可持续性 | 0.15 |
| 资源匹配 | 0.15 |
| 合规风险（反向） | 0.05 |

```
total = 0.20 × need
      + 0.20 × (10 - comp)
      + 0.25 × money
      + 0.15 × durable
      + 0.15 × fit
      + 0.05 × (10 - risk)
```

### 决策阈值

| 总分 | 结论 | 动作 |
|---|---|---|
| **≥ 7.5** | 立项 | 立刻做 3 条测试片 |
| **7.0 - 7.4** | 立项（观察） | 做 1 条试水，看 3 秒完播率 |
| **6.0 - 6.9** | 观察 | 不投入生产，先持续收集该赛道爆款 |
| **< 6.0** | 放弃 | 记录原因，不再回头看 |

### 一票否决项

无论总分多少，命中任一条直接放弃：

- 需要伪造身份或资质才能做
- 核心卖点是「AI 换脸某人」
- 内容本质是搬运/洗稿他人作品
- 涉及荐股、诊疗、代办证件等需要牌照的业务

---

## 四、使用方式

```bash
python3 scripts/track_score.py
```

按提示输入六个分数，脚本会算出总分、给出结论，并把结果追加到 `data/tracks.csv`。

### 打分后的纪律

1. **打分前不要看别人的结论**，否则会为了「想做」而调分
2. **同一赛道隔 30 天重新打一次**，看趋势变化
3. **被放弃的赛道保留记录**，放弃的原因往往比选择更有价值
4. **分数只是过滤器，不是决策者**：≥7 分只是「允许试」，不是「一定成」

---

## 五、常见误判

| 误判 | 表现 | 纠正 |
|---|---|---|
| 把「没竞争」当机会 | `score_comp` 打 2 分 | 先确认 `score_need` 是否也低，可能是没需求 |
| 高估自己的资源 | `score_fit` 打 9 分 | 问：这个信息别人花多少钱能买到？ |
| 忽视变现距离 | 只想着涨粉 | 涨粉不是商业模式，卖东西才是 |
| 合规风险打 0 | 觉得「没人管」 | 出事时是平台先封你，不是监管 |
