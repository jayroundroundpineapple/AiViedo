# 08 · 路线汇总与决策规则

> 这份文档汇总两条建议线的分歧与取舍，并给出**可执行的先后顺序**与**什么时候该改方向**。
> 本文修订了 `docs/06` 的一处判断：**海外不只做分发，0 粉就能接单收钱，单价是国内 5–10 倍。**

---

## 一、一句话结论

> **角色 IP 是资产；小红书图文 + 薯店是验证场；抖音是放大场；海外（Fiverr / Etsy）是提价场。**
> 四件事不冲突，但**必须按「0 粉能不能收钱」排序**，不是按「哪个看起来更大」排序。

---

## 二、两条建议线的对照

| 议题 | 通用建议（视频优先） | 本仓库（变现距离优先） | 汇总采纳 |
|---|---|---|---|
| 核心资产 | 原创角色 IP | 原创角色 IP | ✅ 一致 |
| 主线形态 | 短视频，每周 5–6 条 | 图文为主 | **图文为主，视频每周 1 条** |
| 市场 | 国内外同时 | 国内先 | **国内验证 + 海外接单，两个都做但要分开定位** |
| 首月目标 | 20–24 条视频 | 第一单 | **20 条内容 + 1 单** |
| 变现顺序 | 数字资产放第三层 | 数字产品放第一层 | **数字产品提前**：它是唯一 30 天内能验证的环节 |
| 平台分成 | 主要收入之一 | 国内基本为零 | **不作为目标**，只当意外收益 |
| 素材库 / 提示词库 | 有 | 有 | ✅ 一致 |

**分歧的根源**：短视频方案的假设是「先有流量，再有收入」；本仓库的假设是「先有收入，再放流量」。后者更适合一个人、每天 1 小时、没有供应链的情况——因为流量的成本是时间，收入验证的成本是一个商品。

## 三、核心表：0 粉就能收钱的只有三个口

这张表是整个决策的依据。**"需要粉丝才能变现"的渠道，一律排在有收入之后。**

| 渠道 | 开通门槛 | 需要粉丝？ | 单价量级 | 排序 |
|---|---|---|---|---|
| **小红书薯店** | 实名 + 个人专业号，保证金 1000 元（可后缴） | **否** | ¥9.9–49 | ① 现在 |
| **Fiverr 定制接单** | 注册 + 发布 Gig（作品集 10–15 张） | **否** | $25–200+/单 | ① 现在 |
| **Etsy 数字下载** | 上架费约 $0.2/条 | **否** | $10–80 | ② 有 3–5 个产品后 |
| Adobe Stock / Shutterstock | 注册，上传需勾选 AI 生成 | **否** | $0.1–2.85/次下载 | ③ 素材攒到 100 张 |
| **抖音商品橱窗** | 1000 粉 + 10 条公开视频 + 500 元保证金（可退） | **是** | 佣金 | ④ 到 1000 粉 |
| **抖音星图·图文一口价** | **1000 粉**（有效粉 ≥500） | **是** | 自报价 | ④ 到 1000 粉，优先 |
| 抖音星图·短视频投稿 | 1 万粉（有效粉 ≥500） | 是 | 按播放/转化 | ⑤ |
| 抖音星图·指派任务 | 10 万粉 | 是 | 高 | ⑥ 很久以后 |
| TikTok Creator Rewards | 1 万粉 + 30 天 10 万播放 + 账号在 8 国 | 是 | 极低 | 不建议作为目标 |
| YouTube Shorts 分成 | 1000 订阅 + 90 天 1000 万播放 | 是 | $0.02–0.10 / 千次 | 不建议作为目标 |

**三条必须记住的推论**

1. **抖音不是不能变现，是变现权限被粉丝锁着。** 1000 粉解锁「商品橱窗 + 星图图文任务」，这是图文创作者的第一个抖音收入口，不是 1 万粉。
2. **海外真正的机会不是播放分成，是接单。** Fiverr 上一张 AI 宠物肖像 $40–200，同一张图在国内卖 ¥29。**同样的产能，海外单价高 5–10 倍，而且不需要粉丝。**
3. 因此「先国内后海外」不完全对：**国内负责验证"什么好卖"，海外负责"同样的东西卖更贵"。** 两者可以并行，但商品可以先只在一边上。

## 四、诚实测算：壁纸 + 表情包 + 头像 + 素材包的天花板

先说结论：**这四样加起来，稳定态大约月入 ¥1500–8000，不是月入几万。** 这是方向本身的性质，不是执行问题。

| 品类 | 假设 | 月收入 | 性质 |
|---|---|---|---|
| 壁纸包 ¥9.9 | 30 单/月 | ≈ ¥300 | 引流款，几乎不赚钱 |
| 表情包 ¥9.9 | 5 单/月 | ≈ ¥50 | **不是收入，是 IP 传播工具** |
| 头像/宠物定制 ¥29–49 | 20 单/月 | ≈ ¥600–1000 | 主力现金流，但**是劳动，不被动** |
| 数字素材包 ¥29 | 15 单/月 | ≈ ¥435 | 唯一接近被动的一块 |
| **合计** | 需 5000–1 万粉 + 稳定更新 | **≈ ¥1400–1800** | — |

**所以你的直觉是对的：单靠这四样，难度确实大。** 但要分清两件事：

- **难度大 ≠ 方向错。** 这四样的真实作用是「**地基**」：验证有人愿意付钱、攒下可复用素材、跑通"内容 → 店铺 → 付款"的链路。没有这个地基，后面所有放量都是空转。
- **天花板低的解法不是换品类，是换三样东西**：

| 解法 | 做法 | 单价变化 | 难度 |
|---|---|---|---|
| **换市场** | 同样的图挂 Fiverr / Etsy | ¥29 → $40–200 | 中，需要英文 listing |
| **换客群** | 从 C 端卖图 → B 端卖服务（商家 IP 形象、封面、公众号配图） | ¥29 → ¥300–2000/单 | 中 |
| **换形态** | 从卖单品 → 卖包月（每月 8–15 张图，$300–600/月） | 单次 → 订阅 | 高，但最接近被动 |
| 换品类（最后才考虑） | 教程 / 课程 | 高但不稳定 | 高，且合规风险大 |

**换句话说**：壁纸是「入口」，定制是「现金流」，**包月和 B 端才是「被动收入」真正的载体**。四件套只是通往包月的第一步，不是终点。

## 五、结构：一个资产，三个出口

```
原创角色 IP（唯一需要长期积累的东西）
├── 壁纸 / 头像 / 表情包 ──→ 曝光与点击（起量）
├── 过程视频 · 每周 1 条 ──→ 信任与原创证明（涨粉）
└── 定制 + 素材包 + 包月 ──→ 成交（收钱）
```

**关键纪律**：钩子内容不指望赚钱，成交内容不指望流量。混在一起做，两件都做不好。

## 六、视频到底做不做：做，但它是杠杆不是起点

| 观点 | 说明 |
|---|---|
| **视频的真实作用** | 不是播放分成，是**放大已验证的东西**。一条爆款能带来 1000 粉，而 1000 粉在抖音能解锁橱窗和星图图文任务 |
| **现在做多少** | 每周 1 条，30–60 秒，只拍过程/成品/前后对比 |
| **什么时候提速** | 小红书出现 **≥3 单成交** 之后，再加到每周 3 条 |
| **什么情况下才值得日更** | 已有稳定出单 + 有批量生产流程 + 有明确投放目标，三者同时成立 |
| **明确不做** | 为了播放量做纯视觉奇观；六个平台同时铺；日更 |

**为什么不是现在**：现在做视频，等于用最贵的产能去换最不确定的结果。**先让商品跑通，再用视频放量，顺序错了就是烧时间。**

## 七、阶段推进：按信号，不按时间

| 阶段 | 状态 | 动作 | 进入下一阶段的信号 |
|---|---|---|---|
| **0** | 现在 | 小红书开店 + 30 张壁纸 + Fiverr 挂 1 个定制 Gig | 小红书 **≥1 单**成交 |
| **1** | 有第一单 | 加 Etsy 数字下载；视频提到每周 1 条；优化标题与封面 | 累计 **≥3 单** |
| **2** | 有 3 单 | 上抖音（图文同步），冲 1000 粉；上第二个产品线 | 抖音 **1000 粉**（解锁橱窗+星图图文） |
| **3** | 1000 粉 | 开橱窗、接星图图文任务；素材上传 Adobe Stock | 单月收入 **≥¥2000** |
| **4** | 月入 2000+ | 试包月/B 端服务；考虑 YouTube 长视频沉淀 | — |

**注意**：阶段 0 同时开小红书和 Fiverr，是因为这两个都「0 粉可收钱」，且一个验证需求、一个验证提价空间。

## 八、六周决策规则（给"方向探讨"设成本上限）

到 **2026-12 月中**，只看三个数：

| 指标 | 及格 | 不达标说明 |
|---|---|---|
| 小红书是否有 **≥1 单**成交 | 有 | 商品或定价有问题，不是内容问题 |
| 是否有笔记 **搜索进入占比 ≥20%** | 有 | 标题没埋搜索词，长尾吃不到 |
| **收藏率中位数 ≥5%** | 有 | 内容形态不对，换形态 |

- **两项达标** → 加量，进入阶段 2
- **一项达标** → 只改不达标的那一项，再来 4 周
- **三项全无** → 换**内容形态**（壁纸 → 教程 / 宠物拟人 / 封面模板），**不换平台、不加发布量**

成本上限：6 周 × 每天 1 小时 + ¥100 左右。用这个换一个确定答案，比继续看别人的收入截图便宜。

## 九、来源分级

| 结论 | 来源 | 可信度 |
|---|---|---|
| 抖音星图：入驻无粉丝要求，图文一口价任务需 1000 粉（有效粉 ≥500），短视频投稿需 1 万粉，指派任务需 10 万粉 | 巨量星图官方帮助中心 | A |
| 抖音商品橱窗：1000 粉 + 10 条公开视频 + 500 元保证金；存在 0 粉试运营通道 | 多方教程一致，非官方原文 | C，以后台为准 |
| Fiverr AI 定制：$25–200+/单，平台抽成约 20%，提现约 14 天 | 多方行业文章 + 中文实操复盘 | B/C |
| Etsy 数字下载：上架费约 $0.2，平台费约 6.5%，总抽成约 10–12% | 多篇文章一致 | B/C |
| Adobe Stock / Shutterstock 接受标注 AI 的图片 | 平台政策 + 多方说明 | B |
| 壁纸/表情包/定制/素材包的收入量级 | **本文测算，非实测** | 推算，需用自己的台账替换 |

**最后一句**：第四节的收入表是算术，不是预言。**唯一可信的数字，是你自己台账里 30 天后的那三个数。**
