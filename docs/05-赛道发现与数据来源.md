# 05 · 赛道发现与数据来源

> 你想「拉取抖音/小红书的赛道数据」，这件事有合法路径，也有会让你封号的路径。
> 这份文档只写前者。

---

## 一、先明确原则

**不做自动化爬取。** 原因不是技术做不到，是代价不对：

- 平台用户协议普遍禁止自动化采集，违反面临封号、民事索赔、不正当竞争诉讼
- 抓取内容一旦含用户昵称、头像、主页，就落入个人信息保护法的管辖
- 你的账号是核心资产，不值得为省几小时录入时间去赌

**可用的数据只有四类**：

1. 你自己账号的官方后台数据（最干净、最准）
2. 平台官方开放的分析工具
3. 有授权的第三方数据服务（付费）
4. 你人工观察记录的公开信息

---

## 二、免费官方渠道

| 平台 | 工具 | 能看到什么 |
|---|---|---|
| 抖音 | 创作者中心 · 数据参谋 | 自己账号的完播率、留存曲线、粉丝画像 |
| 抖音 | 巨量算数 | 关键词热度趋势、人群画像、内容供给量 |
| 抖音 | 热点宝 | 上升热点、低粉爆款榜 |
| 小红书 | 创作服务平台 · 灵感笔记 | 品类趋势、热门话题 |
| 小红书 | 蒲公英 | 商单报价参考、达人数据 |
| 视频号 | 创作者中心 | 自己的播放、完播、转发链路 |
| B站 | 创作中心 · 数据中心 | 完播率、互动率、流量来源 |

**最有用的是「低粉爆款」类榜单**：粉丝少但播放高，说明内容本身跑赢了账号权重——这才是可复制的信号。粉丝百万的爆款对你不构成参考。

---

## 三、第三方付费服务

按需选，不要一上来全买：

| 工具 | 擅长 | 适合阶段 |
|---|---|---|
| 蝉妈妈 | 抖音电商、带货榜、商品维度 | 想带货 |
| 飞瓜数据 | 抖音达人、视频、直播 | 做达人号 |
| 千瓜数据 | 小红书笔记、达人、品牌 | 做小红书 |
| 新榜 | 跨平台内容榜、公众号 | 看大盘趋势 |
| 灰豚数据 | 抖音/快手/小红书综合 | 预算有限时的折中 |

**判断要不要买**：如果你能用它找到 3 个以上「低粉爆款 + 你能做」的选题，一个月内就回本了。

## 四、零成本的人工方法（推荐先做这个）

### 30 分钟扫榜法

每周固定 30 分钟，只做一件事：**记录让你停下来的视频**。

| 记录字段 | 说明 |
|---|---|
| 平台 | |
| 账号名 / 粉丝量 | 粉丝量是关键，判断是否「低粉爆款」 |
| 播放 / 点赞 | 记大概量级即可 |
| 赛道关键词 | 3 个以内 |
| **前 3 秒原话** | 逐字记下来，这是最有价值的信息 |
| 钩子类型 | 反常识 / 结果前置 / 冲突 / 痛点 / 悬念 / 对比 |
| 结构 | 几段、每段讲什么 |
| 我能不能做 | 能 / 不能 / 需要什么资源 |

**为什么有效**：AI 分析不了「你为什么会停下来」，但你自己知道。这份主观记录比任何数据工具都准。

### 三个信号判断赛道在涨

1. **供给在增加但还没饱和** —— 搜同一个关键词，近 30 天新号变多，但头部还没固化
2. **评论区有真实需求** —— 不是「哈哈」「支持」，而是「这个多少钱」「怎么做的」「求教程」
3. **有低粉爆款** —— 1 万粉以下的账号能出 10 万+ 播放，说明流量分配还在给新人机会

三个信号同时出现，就值得用 `scripts/track_score.py` 打分。

## 五、数据怎么进台账

| 来源 | 落到哪个文件 | 注意 |
|---|---|---|
| 平台后台导出 | `data/raw/`（不入库） | 原始文件，含个人信息 |
| 整理后的发布数据 | `data/videos.csv` | 只填结构化字段 |
| 每日/每时点快照 | `data/metrics.csv` | 用于画增长曲线 |
| 赛道调研结论 | `data/tracks.csv` | 打分 + 一句话判断 |
| 竞品爆款拆解 | 建议新建 `data/benchmarks.csv` | 见下方字段 |

### 竞品爆款库建议字段

```
bench_id,platform,account,followers,views,hook_text,hook_type,track,structure,can_i_do,notes
```

`hook_text` 要**逐字记录**前 3 秒原话，不要概括。这是整个库里最有价值的一列。

---

## 六、一个提醒

数据工具能告诉你「什么在火」，但告诉不了你「你能不能做」。

赛道选择的真正变量是**资源匹配**——你有没有别人没有的信息、渠道、身份。这一项 AI 和数据都替不了你，只能自己诚实打分。

详见 [`03-赛道评估模型.md`](03-赛道评估模型.md) 的 `score_fit` 维度。
