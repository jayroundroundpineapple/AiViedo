# 04 · SOP：单条视频生产

> 目标：把「做一条视频」从靠状态变成靠流程。
> 熟练后单条应在 **4-6 小时**内交付，其中 AI 生成等待时间约占一半。

---

## 阶段一 · 选题（30 min）

**产出**：一句能说清的钩子

- [ ] 从 `data/tracks.csv` 里选一个 `active` 赛道
- [ ] 写 5 个候选钩子，每个不超过 20 字
- [ ] 用「反常识测试」筛：这句话是不是大多数人会不同意/没想到？
- [ ] 留下最强的 1 个

**判断标准**：如果这句话你自己说出来都觉得平淡，观众一定划走。

**常见错误**：选题时想「我想讲什么」，应该想「他为什么会停下来」。

---

## 阶段二 · 脚本（60 min）

**产出**：60 秒分秒脚本 + 8 个镜头

用 `templates/脚本模板.md`，结构固定：

| 时间 | 功能 | 内容要求 |
|---|---|---|
| 0-3s | **钩子** | 反常识断言 / 结果前置 / 冲突。**不介绍自己，不铺垫** |
| 3-15s | **立题** | 把钩子展开成一个具体问题 |
| 15-45s | **推进** | 每 8-10 秒一个信息点，共 3-4 个 |
| 45-55s | **转折** | 一个反转或代价，避免平铺直叙 |
| 55-60s | **收口** | 一句话结论 + 轻引导（不硬要赞） |

**纪律**：脚本必须写到「每一秒在说什么」。写不出来就说明内容不够，回去改选题。

---

## 阶段三 · 出图定妆（1-2 h）

**产出**：1 张主角色定妆图 + 每个场景 1 张参考图

- [ ] 正脸 + 全身各一张，分辨率尽量高
- [ ] 确定光线基调（暖/冷、硬/柔）并写进 prompt 固定段
- [ ] 把「角色描述段」单独存下来，后续每个镜头原样复用

**关键**：这一步偷懒，后面 8 个镜头会生成 8 张不同的脸，全部作废重来。

---

## 阶段四 · 图生视频（半天）

**产出**：8 个 5-10 秒片段

单镜头 prompt 结构（四要素，缺一不可）：

```
【景别】中景
【主体动作】女性转身看向窗外，右手轻触发梢
【运镜】镜头缓慢推近
【光线氛围】傍晚逆光，暖色调，轻微镜头光晕
【一致性】保持参考图中的人物特征与服装
```

**纪律**：

- 一个 prompt 只做一件事，不要在一个镜头里塞两个动作
- 每个镜头生成 3-4 次，挑最好的一条，**废片率 50% 是正常的**
- 生成后立刻命名 `video_id-shot01.mp4`，别等最后一起整理

---

## 阶段五 · 配音剪辑（2 h）

**产出**：成片

- [ ] 配音：真人录音优先；用 AI 音色时选「有呼吸感」的，不要播音腔
- [ ] 字幕：剪映自动识别后**逐句校对**，错别字比画面糊更劝退
- [ ] 卡点：每 2-3 秒一次画面变化，避免超过 4 秒的静止镜头
- [ ] 音效：转场、强调处加轻音效，音量压到 -20dB 以下
- [ ] **加「AI 生成」标识**（合规硬要求，见 `docs/02-合规红线.md`）
- [ ] 封面：单独做，不要用视频截图

---

## 阶段六 · 发布与登记（30 min）

- [ ] 标题 + 话题标签（用 `prompts/04-标题与封面.md` 的公式）
- [ ] 发布后**立刻**登记 `data/videos.csv`，填完除数据类外的所有字段
- [ ] 生成 `video_id` 并重命名成片文件

### 数据回填节奏

| 时点 | 动作 |
|---|---|
| 1h | 记一条 `metrics.csv` 快照，看冷启动 |
| 6h | 快照，判断是否进入第二波推荐 |
| 24h | 快照 |
| **72h** | 回填 `videos.csv` 全部数据字段 + 写 `notes` 结论 |

### `notes` 怎么写

不是描述，是**结论**。

- ❌ 「发了条关于剪辑技巧的视频，播放还行」
- ✅ 「钩子有效（3s 完播 42%），但 25s 处掉量明显，怀疑信息密度不够」

---

## 复盘：48 小时后必做

用 `templates/复盘模板.md`，回答三个问题：

1. **3 秒完播率** 高于/低于该赛道均值？→ 钩子行不行
2. **完播率 / 3 秒完播率** 的衰减比是多少？→ 中段节奏行不行
3. **涨粉 / 播放** 的比例？→ 内容是否让人想持续看

### 诊断表

| 症状 | 病因 | 处方 |
|---|---|---|
| 3s 完播 < 30% | 钩子无效 | 换 `hook_type`，前 3 秒只留冲突 |
| 3s 好，完播差 | 中段拖 | 砍掉铺垫，每 8 秒一个信息点 |
| 完播好，不涨粉 | 内容太「用完即走」 | 加系列感，结尾预告下一条 |
| 数据都不错但没转化 | 变现路径没设计 | 评论区/主页挂承接入口 |

---

## 单条成本核算

```
单条成本 = 人工耗时(h) × 时薪 + AI 调用费用 + 素材授权费

例：4h × 50 元 + 30 元 API + 0 = 230 元
若接单报价 300 元/条，毛利 70 元，毛利率 23% —— 太低
```

**毛利率低于 50% 说明流程还没产品化**，要么提价，要么把 `cost_min` 压下来（模板化、批量生成）。
