# 02 · 脚本提示词

> 目标：把钩子扩成一条 60 秒、分秒可控的脚本。
> **不要直接让 AI「写一个短视频脚本」**，那样出来的一定是「大家好，今天我们来聊聊…」。

---

## P1 · 60 秒分秒脚本

```
你是短视频编剧。请为下面这个钩子写一条 60 秒口播脚本。

钩子：{{钩子}}
赛道：{{赛道}}
观众：{{人群}}

结构必须严格按这个时间轴：
- 0-3s 钩子：原样使用我给的钩子，不要改
- 3-15s 立题：把钩子展开成一个具体问题，给一个具体场景
- 15-45s 推进：3 个信息点，每个 8-10 秒，必须有具体数字或例子
- 45-55s 转折：一个反转、代价或反例，避免一路平铺
- 55-60s 收口：一句话结论，加一句轻引导（不要「点赞关注」）

输出格式（表格）：
| 时间 | 口播原文 | 画面描述 | 作用 |

要求：
- 口播必须是能直接念出来的口语，句子长度不超过 15 字
- 每句话都要有信息，不要过渡句、不要「接下来我们看看」
- 全文不超过 220 字（60 秒的中文口播上限）
```

---

## P2 · 口语化改写

AI 写出来的稿子普遍「书面感重」。用这条改：

```
下面这段稿子读起来太像文章，不像说话。请改写成真人口播的感觉：

{{原文}}

改写要求：
1. 拆长句，每句不超过 15 字
2. 删掉所有书面连接词：因此、然而、综上、首先其次
3. 加入口语停顿标记「，」「。」
4. 把抽象名词换成具体动作
5. 保留信息量，不要为了口语化而变水

改完标注：原文字数 / 改后字数 / 预计口播时长（按每秒 3.5 字算）
```

---

## P3 · 信息密度诊断

```
这是我的 60 秒脚本。请逐句判断「这句话是否推进了信息」：

{{脚本}}

对每一句标记：
- 【必须】删了观众就听不懂
- 【可选】删了更紧凑
- 【删掉】纯过渡、重复、废话

最后给出：删减后的脚本、删减比例、以及「删掉 X% 后节奏是否还成立」的判断。
```

**标准**：60 秒脚本里「删掉」类句子占比超过 20%，说明结构有问题，重写。

---

## P4 · 多平台差异化改写

同一条内容发不同平台，开头必须不一样：

```
这是我的核心内容：{{内容}}

请分别改写三个版本：
1. 抖音版：前 3 秒必须是冲突或反常识，节奏最快，总长 45-60 秒
2. 小红书版：开头给「结果」或「身份认同」，语气更像朋友分享，总长 60-90 秒
3. 视频号版：开头给「价值承诺」，语气更稳，适合中年受众，总长 60-90 秒

三个版本共用同一套信息点，但开头 15 秒必须完全不同。
```

---

## 脚本自检清单

发布前过一遍：

- [ ] 前 3 秒有没有一句能让人停下来的话
- [ ] 每 8-10 秒是否有一个新信息点
- [ ] 有没有「大家好」「今天分享」这类废话开场
- [ ] 数字和事实是否核实过
- [ ] 结尾有没有给「继续看下去」的理由（系列感）
- [ ] 全文能否在 60 秒内念完（中文约 210-220 字）
