# 04 · 标题与封面提示词

> 标题决定点击，封面决定停留。这两样加起来，等于「3 秒完播率」的一半。

---

## 一、标题公式（选一个用，不要混）

| 公式 | 结构 | 示例 |
|---|---|---|
| **反常识** | 「其实 X 不是 Y，而是 Z」 | 「其实剪辑卡点不是踩音乐，是踩呼吸」 |
| **结果前置** | 「我用 X 做到了 Y」 | 「8 个镜头，我把成本压到 30 块」 |
| **代价** | 「做 X 之前，你必须知道 Y」 | 「买 AI 会员之前，先看这三个坑」 |
| **对比** | 「A 和 B 的差别，不在 C」 | 「爆款和废片的差别，不在画质」 |
| **数字具体** | 「N 个 X，第 M 个最关键」 | 「6 个钩子，第 4 个让我涨了 3000 粉」 |
| **身份认同** | 「做 X 的人，都该知道这个」 | 「自己剪片的人，都该知道这个设置」 |

### 禁用清单

- ❌ 「必看」「干货」「建议收藏」—— 平台判定低质
- ❌ 全大写、全感叹号
- ❌ 标题与内容不符（完播率会崩，且影响账号权重）
- ❌ 超过 20 字（移动端会截断）

## P1 · 批量标题生成

```
请为这条视频生成 12 个标题，视频核心内容是：{{内容}}

要求：
1. 分别使用这 6 个公式各 2 个：反常识 / 结果前置 / 代价 / 对比 / 数字具体 / 身份认同
2. 每条不超过 18 字
3. 不使用「必看」「干货」「建议收藏」「震惊」这类词
4. 必须有具体信息（数字、名词、场景），不要空泛

输出表格：标题 | 公式 | 预估点击理由
最后推荐 3 个，说明为什么。
```

## P2 · 标题 A/B 对照

同一条视频在不同平台用不同标题，用台账记录哪个更好：

```
请把下面这个标题改成三个方向不同的版本，保持信息量不变：

原标题：{{标题}}

版本 A：更强调「损失」（不这么做会怎样）
版本 B：更强调「收益」（这么做能得到什么）
版本 C：更强调「身份」（谁该看）

每个版本说明它适合什么样的观众心理。
```

**用法**：A/B 结果记进 `data/videos.csv` 的 `notes`，攒够 10 组就能看出你的受众吃哪一套。

## 三、封面文案

封面只有 2 个信息位：**主文案**（6-10 字）+ **辅助信息**（可选，3-5 字）。

### 主文案写法

| 类型 | 写法 | 示例 |
|---|---|---|
| 冲突式 | 两个对立概念并置 | 「AI 做的 / 我做的」 |
| 数字式 | 大数字 + 单位 | 「30 元 / 1 条」 |
| 提问式 | 一个具体问题 | 「为什么第 3 秒？」 |
| 结论式 | 直接给判断 | 「别做全 AI」 |

### 封面纪律

- [ ] 主文案 ≤ 10 字，字号足够大（手机上一眼能读）
- [ ] 不要用视频截图当封面，单独做
- [ ] 人脸 > 纯文字（除非文字极强）
- [ ] 对比类封面用左右分屏，效果最好
- [ ] 保持系列视觉统一（同字体、同色系），让人认出是你的

## P3 · 封面文案生成

```
请为这条视频设计 5 个封面方案，视频内容是：{{内容}}

每个方案给出：
- 主文案（≤10 字）
- 辅助文案（≤5 字，可空）
- 画面构成（主体是什么、位置、留白在哪）
- 配色建议（2 个颜色）

要求：5 个方案分别用不同策略（冲突 / 数字 / 提问 / 结论 / 人物特写），
并且都必须在手机小图上 1 秒内读懂。
```

## 四、话题标签

| 类型 | 数量 | 作用 |
|---|---|---|
| 大词（赛道级） | 1-2 个 | 进入大流量池 |
| 中词（细分） | 2-3 个 | 精准触达 |
| 小词（长尾/自建） | 1-2 个 | 建立内容集合，方便回看 |

**不要堆 10 个标签**，平台会判定为标签滥用。
