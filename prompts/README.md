# prompts · 提示词库

> 提示词不是收藏品，是**工具**。用得上的留下，用不上的删掉，别堆成垃圾场。

## 使用约定

**1. 变量用 `{{双花括号}}` 标注**

复制后先替换变量，别带着 `{{赛道}}` 直接发给模型。

**2. 好用的 prompt 要回写**

如果你在某次实践中改出了效果更好的版本，**直接改这个文件**，不要另存一份。版本多了就没人看了。

**3. 不存原始对话**

聊天记录不入库。有价值的结论提炼成一句话，写进对应文档。

**4. 标注有效性**

每条 prompt 后面可以加一行实测记录：

```
<!-- 实测：2026-11 · 赛道T01 · 10条中6条3s完播>40% -->
```

## 提示词的三个通病

| 通病 | 表现 | 解法 |
|---|---|---|
| 太笼统 | 「写一个吸引人的脚本」 | 给结构、给字数、给禁用词 |
| 没约束 | 输出格式随机 | 指定表格/列表，指定字段 |
| 不迭代 | 一次不满意就换工具 | 先改 prompt 三轮再考虑换 |
