# 03 · 分镜与画面提示词

> AI 视频崩坏的两个原因：**角色不一致**、**一个 prompt 塞太多事**。
> 这份文档解决这两个问题。

---

## 一、单镜头 prompt 的四要素结构

每个镜头必须写清四件事，缺一不可：

```
【景别】中景 / 近景 / 特写 / 全景
【主体动作】谁 + 做什么 + 做到什么程度
【运镜】固定 / 推 / 拉 / 摇 / 跟随
【光线氛围】时间 + 光源方向 + 色温 + 质感
```

### 完整示例

```
【景别】中景
【主体动作】三十岁女性站在窗边，右手抬起轻触发梢，视线从窗外缓缓移回镜头
【运镜】镜头缓慢推近，幅度很小
【光线氛围】傍晚侧逆光，暖橙色调，窗框有轻微光晕
【一致性】保持参考图中的发型、脸型、米色针织衫
```

### 反面示例（一定崩）

```
❌ 一个女孩在咖啡店工作，然后她站起来走到外面，路上遇到朋友聊了几句，天渐渐黑了
```

问题：三个场景、四个动作、时间跨度大。AI 无法在一个 8 秒镜头里完成叙事。

---

## 二、角色一致性方案

### 方案 A：参考图 + 固定描述段（最稳）

1. 先出一张定妆图（正脸 + 全身）
2. 把角色描述写成固定段落，**每个镜头原样复制**

```
【角色固定段】
三十岁亚洲女性，鹅蛋脸，及肩黑发微卷，米色高领针织衫，
无明显妆容，眼神平静。身形偏瘦，身高约 165cm。
```

3. 每个镜头 prompt = 固定段 + 该镜头的四要素

### 方案 B：固定 seed

多数工具支持 seed。同一角色所有镜头用同一个 seed + 同一张参考图，只改动作描述。

### 方案 C：少切镜头

如果一致性始终做不好，**减少镜头数量**比死磕更划算。8 个镜头里 3 个是同一场景的不同角度，观众不会觉得单调，但会记住这张脸。

---

## 三、镜头语言速查

| 想要的效果 | 用什么 |
|---|---|
| 压迫感、紧张 | 特写 + 固定镜头 + 冷光 |
| 亲近感、信任 | 近景 + 轻微手持 + 暖光 |
| 史诗感、宏大 | 全景 + 缓慢横摇 + 逆光 |
| 节奏加快 | 短镜头（2-3 秒）+ 硬切 |
| 情绪停顿 | 空镜 + 环境音，2 秒 |
| 转折 | 景别突变（全景直接切特写） |

## 四、常用场景 prompt 模板

### 人物口播类

```
【景别】近景
【主体动作】{{角色固定段}}，正视镜头说话，头部有轻微自然摆动，偶尔眨眼
【运镜】固定机位，无运动
【光线氛围】{{室内/室外}}，柔光，主光来自{{左/右}}前方 45 度
【一致性】严格保持参考图人物特征
```

### 产品展示类

```
【景别】特写
【主体动作】{{产品}} 在纯色台面上缓慢旋转 90 度，表面有细微高光流动
【运镜】镜头轻微环绕
【光线氛围】柔光箱布光，背景纯色渐变，无杂物
【一致性】产品外形、logo 位置、颜色严格还原参考图
```

### 空镜/过渡类

```
【景别】全景
【主体动作】无人，{{场景}} 中只有自然元素运动（云、水、树叶、灰尘颗粒）
【运镜】极缓慢推近
【光线氛围】{{时间}}，{{色温}}，景深较浅
```

## 五、生成纪律

| 纪律 | 说明 |
|---|---|
| 一镜一事 | 一个 prompt 只做一件事，塞两件事必崩 |
| 5-10 秒 | 超过 10 秒的动作连贯性会明显下降 |
| 生成 3-4 次再选 | 废片率 50% 是正常的，不要生成一次就放弃 |
| 立刻命名 | `video_id-shot01.mp4`，别等最后一起整理 |
| 记录 prompt | 好的 prompt 存进本文件对应模板，别只存在脑子里 |

## 六、常见崩坏与对策

| 崩坏表现 | 原因 | 对策 |
|---|---|---|
| 脸变了 | 参考图未固定 / seed 变了 | 用固定段 + 同 seed |
| 手部畸变 | 模型通病 | 减少手部动作，或让手出画 |
| 动作没做完 | 时长不够 | 拆成两个镜头 |
| 画面抖动 | 运镜描述过度 | 改成「固定机位」 |
| 风格漂移 | 光线描述不一致 | 把光线段也固定下来 |
| 文字乱码 | 模型不擅长生成文字 | 文字后期加，不要交给模型 |
